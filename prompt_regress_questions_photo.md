# Промпт: фото справа в блоке «Вопросы» (регрессия)

Файл: `СтраницыСайта(Код)/tilda-regressiya.html`

## Задача

В блоке `#regress-requests` (H2 «С какими запросами идут в регрессию?» / «З якими запитами йдуть у регресію?») добавить фото справа от текста. Сейчас блок — одна колонка (`<div class="fade-in">` с h2, двумя `<ul class="rg-list">`, `.rg-note` и `.rg-body`). Нужно превратить его в двухколоночную сетку: текст слева, фото справа — по образцу уже существующего блока `#regress-hero` (`.rg-hero-grid` / `.rg-hero-photo` / `.rg-hero-text`).

Фото (вставить как есть, это финальная ссылка, не плейсхолдер):
```
https://optim.tildacdn.net/tild3964-6430-4338-b733-346431613164/-/format/webp/IMG_4826.jpeg.webp
```

## Что сделать

1. **HTML.** Внутри `<section id="regress-requests"><div class="rg-container">` заменить одиночный `<div class="fade-in">` на грид с двумя колонками:
   - `<div class="rg-requests-grid">`
     - `<div class="rg-requests-text fade-in">` — весь существующий контент блока (оба h2, оба `<ul class="rg-list">`, оба `.rg-note`, оба `.rg-body`) без изменений текста.
     - `<div class="rg-requests-photo fade-in">` — `<img>` с указанной ссылкой, атрибут `alt` осмысленный (например, `alt="Регресія — запити"` / подбери по контексту, укр. и рус. версии не нужны, alt один).

2. **CSS.** Добавить новые классы `.rg-requests-grid`, `.rg-requests-photo`, `.rg-requests-photo img`, `.rg-requests-text` — **копия паттерна** `.rg-hero-grid` / `.rg-hero-photo` / `.rg-hero-photo img` / `.rg-hero-text` (строки ~247–275 файла), но текст занимает **бо́льшую** долю ширины, а фото — меньшую (это блок с текстом-акцентом, не hero): например `flex: 1 1 58%` для текста и `flex: 0 0 38%` / `max-width: 38%` для фото, `gap: 48px`. Высоту фото подбери так, чтобы карточка смотрелась пропорционально (не растягивай на всю высоту текста — ориентируйся на `height: 480px` с `object-fit: cover`, `object-position: center`).
   - `border-radius: 12px` на фото (единственное согласованное исключение из общего правила ≤4px, как у `.rg-hero-photo img`).
   - Никаких `box-shadow`, `filter`, наложений цвета.
   - Не добавляй новых цветов — только уже существующие переменные `:root`, если понадобится (здесь заливка не нужна, только изображение).

3. **Адаптив (`@media (max-width: 768px)`).** По образцу существующего мобильного блока для `.rg-hero-grid` (строки ~747–760): добавить `.rg-requests-grid { flex-direction: column; gap: 32px; }`, `.rg-requests-photo { max-width: 100%; width: 100%; }`, `.rg-requests-photo img { height: 70vw; }`, `.rg-requests-text { flex: 1 1 auto; }`. Фото на мобайле идёт **под** текстом (текст важнее списков вопросов, читается первым).

4. **Не трогать:** тексты (`rg-list`, `rg-note`, `rg-body` на обоих языках), `lang="ru"`/`lang="uk"` атрибуты, остальные секции файла, `<!DOCTYPE>/<html>/<head>/<body>` по-прежнему не добавлять (Tilda-вставка).

## Проверка перед сдачей

- Блок `#regress-requests` на десктопе: текст слева (шире), фото справа (уже), выровнены по верху текста.
- На ширине ≤768px — колонка друг под другом, фото не обрезает лицо/композицию криво (`object-position: center`, проверить визуально при необходимости скорректировать).
- Никаких новых hex/rgb/hsl вне уже одобренной палитры проекта.
- Файл по-прежнему валиден как Tilda-вставка (без `<!DOCTYPE>` и т.д.), консоль браузера чистая.
